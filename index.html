Profile Card

A personal profile card built with HTML and CSS. It includes my profile information, image, and professional links.

Technologies: HTML, CSS

View Live Project View Source Code
Read Case Study

I created a personal profile card using HTML and CSS to introduce myself and provide visitors with a quick overview of my professional identity. The goal was to create a clean, organized design that displays my name, profile information, image, and professional links. The intended audience includes people who want to learn more about me and access my professional profiles. I used HTML to structure the content and CSS to control the layout, spacing, padding, borders, rounded corners, and shadow effects. One design decision I made was using rounded corners and a subtle shadow to make the profile card stand out while keeping the appearance professional. I also added hover effects to the social media buttons to make the links more interactive. I checked the project by opening the live website and verifying that the profile information, image, and social links displayed correctly. I also tested the hover effects. One improvement I would make is refining the responsive layout for different screen sizes and adding more information about my technical interests and experience.

Game Collection Toolkit

A JavaScript project that validates, searches, filters, sorts, and summarizes game collection records.

Technologies: JavaScript

View Source Code
Read Case Study

I created a JavaScript data toolkit designed to manage and process video game collection records. The project includes seven functions that validate, normalize, filter, search, sort, summarize, and generate reports from game collection data. The intended users are people who want to organize and work with game collection information. The goal was to make sure records could be processed accurately while handling different types of input. I used JavaScript functions to separate each task into manageable parts. One important decision was to validate and normalize records before processing them. This helps maintain consistent data and prevents invalid or incomplete records from causing problems. To verify my work, I created a test harness containing 14 test cases. These tests checked the different functions and how they handled valid and invalid data. All 14 test cases passed. One improvement I would make in the future is adding a visual interface so users can interact with their game collection more easily instead of relying only on JavaScript functions.
